功能

它解决的是「看一眼就走」这件事

同类软件大多假设你要认真管理任务，于是越做越重。LumistDo 反过来： 它就是一张纸，贴在桌面上，存在感越低越好。

置底 + 固定位置

大多数同类软件只有「置顶」，它还能沉到所有窗口的最底层，跟壁纸融为一体。固定之后每次出现都在同一个位置，肌肉记忆能记住。

位置模式快捷键

平时待在底层不动，桌面窗口太多、想扫一眼清单的时候，按一下快捷键就浮上来，看完再按回去。

缩略模式

顶栏整块渐隐，只剩下任务文字。鼠标贴到顶部才露出图标，平时几乎看不出那是个窗口。

真毛玻璃

调用系统接口把窗口背后的桌面内容真正模糊掉，而不是贴一层假的半透明色块。

轻

一个 1.9 MB 的 exe，一个进程就起来了。不联网、不带数据库、不常驻后台服务。

数据在自己手里

所有任务就是 %APPDATA%\LumistDo 下的两个 JSON 文件。想备份直接复制，想搬走直接拷过去。

界面

三种存在方式

从「完全不想看见」到「想看详细一点」，按场景切换。

配色

六套预设

深空、暖夜、毛玻璃、海洋、薰衣草、素白，挑一个配你的壁纸。

安装

下载、双击、完事

  1. 1
    下载安装包

    从 GitHub Releases 取最新版，当前是 v1.3.2（31 MB）。

  2. 2
    双击装完

    不需要管理员权限，装完会在开始菜单和桌面留下快捷方式。

  3. 3
    首次运行可能被 SmartScreen 拦一下

    安装包没有做代码签名（个人项目，签名证书要钱）。点「更多信息 → 仍要运行」即可。
