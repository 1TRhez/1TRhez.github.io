LumistDo 览明贴：一个贴着桌面的任务便签

发表于2026-10-04|更新于2026-10-04|技术笔记
|浏览量:

写了个小软件，叫 LumistDo（览明贴） —— 一个常驻在桌面上的任务便签。

为什么写它

起因很朴素：我想找个桌面任务清单，结果找了一圈没一个顺手的。

  • 好用的太大太臃肿，打开它像启动了一整个工作台
  • 轻的花里胡哨，好看的功能转手就要 VIP
  • 开源的倒是干净，但功能太少，缺的正好都是我想要的

找烦了，索性自己写了一个。

名字

LumistDo = Luminous + List + Do，取「去执行清晰可见的清单」的意思。

中文名刚好也近似发音/ˈluːmɪst/

本来是想叫「某某 ToDo」的，围绕 ToDo 想了半天，发现无论怎么拼都有一堆重名的。索性放弃这条路，重新换了个思路起名。

长这样

半透明的圆角卡片，边缘是羽化的，跟桌面背景之间没有硬邦邦的一条边。

上面是任务列表，左边一个空心圆点，点一下就算做完了。底部收着「已完成」，右边那个齿轮是设置。

我最想要的其实是「存在感弱」

同类软件基本都有置顶，但很少有置底。

我不是想要一个”随时提醒我”的清单，我想要的是一个不影响我工作的清单 —— 像一张随手便利贴，贴在壁纸上面，跟背景几乎融为一体。

所以做了这几件事：

添加了很多软件没有的置底 + 固定位置 功能。让它沉在最底层，不去跟别的窗口抢位置。再配上可调的透明度，以及毛玻璃效果，哪怕是置顶状态也完全不挡信息 —— 半透明能透出后面的内容，边缘又是柔的。

位置模式的快捷键。 平时它老实待在底层。桌面窗口一多、想快速扫一眼清单的时候，一个快捷键就能把它按出来，看完再按回去。不用去托盘里翻，也不用先点到它。

缩略模式。 顶栏整块渐隐，屏幕上只剩任务文字；鼠标贴到顶部，图标才露出来。

窗口层级三态：普通 / 最上层 / 最底层一键循环，另有「固定位置」防误拖。

划掉的任务不消失。 点圆点之后收到底部的「已完成」栏，手滑点错了点一下就能还原。

按住就能拖动排序。 想到什么先写下来，回头再一次性理顺序。

顺手的地方

操作 效果
点 + / Ctrl+N 新建一条，光标自动落在输入框
双击任务文字 就地编辑，回车或点别处保存，Esc 取消
点任务左边的圆点 标记完成，任务移到「已完成」栏
按住任务上下拖 调整顺序
右键任务行 编辑 / 删除
Ctrl+Alt+1 / 2 / 3 切换层级、固定位置、缩略模式

那三个快捷键是注册成系统级热键的，所以在别的程序里打字也能触发 —— 想让它出现就出现，不用先去找窗口。

配色有六套预设（深空 / 暖夜 / 毛玻璃 / 海洋 / 薰衣草 / 素白），不喜欢的话背景色和字体色也能单独挑。界面中英双语。

关于「轻」

这大概是它最让我满意的地方：

  • 一个进程、一个 1.9 MB 的 exe
  • 不联网、没有数据库、没有后台服务和更新检查
  • 常驻内存几十 MB，之后基本不动
  • 数据就是两个 JSON 文件：%APPDATA%\LumistDo\settings.json 和 tasks.json，纯文本，想备份直接复制走

卸载走「设置 → 应用 → 已安装的应用」，卸载的时候它才会问你要不要连数据一起删掉。

中间砍掉和改掉的东西

有一半时间不是在写功能，是在跟自己先前的主意打架。记几个。

自动隐藏：做出来了，然后砍了

最初有个功能：鼠标焦点不在软件上时，它自动半透明隐藏，挺像那么回事。

但判断逻辑很难写对，而且经常隐藏了就永久不显示了 —— 想把它叫出来，连设置都打不开。修了几轮发现这事从根上就不对：我要这个任务清单，本来就是为了看它，我把它藏起来是图什么。

于是整个功能砍掉，需求换成用快捷键切换窗口位置 —— 想扫一眼按一下就行，比自动隐藏可控得多。

顺带为了以绝后患（万一以后还有修不掉的 bug），在设置里加了个一键重置按钮 —— 点一下恢复默认设置。

置顶和置底会打架

这两个东西逻辑上是冲突的，一开始没注意，后来发现它们会互相卡出 bug。

最后改成：每种窗口模式只能单独存在，选了置底就不能同时置顶，状态互斥。

毛玻璃和圆角是天生矛盾的

Windows 的毛玻璃效果做不出圆角和边缘羽化 —— 系统给你的是个方框，而这个软件的界面是圆润的卡片，两者一叠加，方框的直角就会硬生生露在外面。

最后是用巧妙的藏色手法把这个方框毛玻璃隐进圆角界面里的：让方框边缘的颜色跟它背后融到一起，视觉上就”没有”那个直角了。

下载

到 Releases 或者源码仓库 1TRhez/LumistDo 下载 LumistDo-Setup-v1.3.2.exe（31 MB，Windows 10 / 11）。

最新这版（v1.3.2）加了自选安装位置：默认装在 %LOCALAPPDATA%\Programs\LumistDo，全程不弹 UAC；想装到 C:\Program Files 这种地方，在安装向导第一页选「为所有用户安装」就行。

已知的不足

  • 安装包没有代码签名，第一次运行 Windows SmartScreen 会拦一下，点「更多信息」→「仍要运行」就行
  • 数据只存本机，没有云同步。换电脑要手动搬那两个 JSON
  • 快捷键是独占注册的：如果系统里已经有别的程序占用了 Ctrl+Alt+1/2/3，在这里就得改绑

后面会慢慢更新优化，不断完善。
